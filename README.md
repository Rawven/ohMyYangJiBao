# 明天割肉吧兄弟 🐔🍗

因为不想给养🐔宝充VIP自己写了个能大概用的

## 功能

| 页面 | 说明 |
|------|------|
| **AI 对话** | 自然语言查询基金、分析持仓、对比基金、生成图表。支持多轮对话 |
| **总览** | 持仓市值、盈亏分布、收益曲线 |
| **基金市场** | 浏览基金列表，筛选基金类型、净值区间 |
| **我的持仓** | 管理持有的基金份额和成本 |
| **交易记录** | 记录买入卖出操作 |
| 基金详情 | 查看单只基金的持仓、阶段收益、风险指标、经理信息 |
| 基金对比 | 多只基金并排对比 |
| 行业分析 | 查看申万一级行业的资金流向和热度 |
| 指数估值 | 主要指数的 PE/PB 估值百分位 |

## 快速开始

### 后端

```bash
cd fund-tracker-server
export DEEPSEEK_API_KEY=sk-your-key-here
mvn spring-boot:run
```

后端默认启动在 `http://localhost:8080`。首次启动会自动建表并初始化示例基金数据。

### 前端

```bash
cd fund-tracker-web
npm install
npm run dev
```

前端默认启动在 `http://localhost:3000`，自动代理 API 到后端。

## 使用示例

1. 打开 `http://localhost:3000`，左侧导航进入 **AI 对话**
2. 输入 `帮我分析我的持仓风险` — AI 会自动调用工具查询持仓、计算集中度、行业暴露
3. 输入 `最近哪些基金表现比较好` — 返回涨幅榜和推荐
4. 上传持仓截图，自动识别并导入基金
